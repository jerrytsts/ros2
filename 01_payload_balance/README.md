# 项目一：双臂搬运负载的自适应平衡

这是独立实现的 MuJoCo 实验，不沿用 OpenHUTB 现有源码结构。研究对象是一台
在固定步行台上保持站姿的简化双足机器人；胸前负载在 0、2、4 kg 间变化时，
躯干俯仰动力学随之改变。

## 设计

- 自建 14 自由度、12 执行器 MuJoCo 装置。
- 双腿由髋、膝、踝位置伺服维持站姿。
- 躯干绕横轴可倾，两个独立力矩执行器模拟踝部与髋部平衡补偿。
- 扰动由步行摆动项、负载耦合项和周期脉冲共同组成。
- 参考 PD 控制提供安全示教。
- NumPy 网络为 `8 → 24 → 16 → 2`，学习从姿态、角速度、负载和扰动到补偿力矩的映射。

## 快速运行

```powershell
python -m pip install -r requirements.txt
python main.py train
python main.py test
python main.py evaluate --seconds 20
python main.py demo --mass 4 --seconds 8
```

```powershell
powershell -ExecutionPolicy Bypass -File .\run_assignment.ps1
```

## 结果

20 秒、三个负载、三种控制器：

| 负载 | 控制器 | 平均绝对俯仰 | RMS | 峰值 | 是否跌倒 |
| --- | --- | ---: | ---: | ---: | --- |
| 0 kg | 无反馈 | 23.24° | 23.75° | 31.82° | 否 |
| 0 kg | PD | 8.16° | 8.38° | 11.64° | 否 |
| 0 kg | 学习策略 | 8.17° | 8.39° | 11.62° | 否 |
| 2 kg | 无反馈 | 24.84° | 25.47° | 32.03° | 是 |
| 2 kg | PD | 10.12° | 10.30° | 13.36° | 否 |
| 2 kg | 学习策略 | 10.12° | 10.31° | 13.40° | 否 |
| 4 kg | 无反馈 | 15.10° | 18.08° | 32.07° | 是 |
| 4 kg | PD | 11.50° | 11.66° | 14.88° | 否 |
| 4 kg | 学习策略 | 11.54° | 11.70° | 15.22° | 否 |

学习策略在 2 kg 和 4 kg 下避免了无反馈情形的跌倒，同时把平均绝对俯仰从
`24.84°` / `15.10°` 降到 `10.12°` / `11.54°`。它与 PD 教师非常接近，
说明行为克隆学会了参考控制律，而不是获得了超越教师的物理能力。

## 边界

该模型突出负载质量对俯仰的影响，腿部运动主要提供可视化站位，不包含完整
三维双足步态、足底接触优化或自由场地行走。因此结论应表述为“负载变化下的
俯仰补偿”，不能写成“完成了任意地形上的动态行走”。
