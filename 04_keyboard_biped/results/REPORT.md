# 键盘驱动双足实验报告

## 控制结果

| 验证项 | 结果 |
| --- | --- |
| 模型关节数 | 10 |
| 执行器数量 | 10 |
| 前进 1 秒 @ 0.3 m/s | 0.300 m |
| 转向 0.5 s @ 0.5 rad/s | 0.250 rad（14.32°） |
| 转向后前进 0.5 s | 0.150 m，方向与偏航角一致 |
| 零指令 | 位置保持不变 |
| 测试 | 8 项通过 |

## 实现说明

键盘层只在收到按键时更新目标速度；方向键和字母键映射相同。积分器按当前
偏航角把前向速度分解为世界系位移。步态相位随前向速度变化，髋、膝、踝和
手臂目标角由正弦轨迹产生。

机器人底座通过 MuJoCo mocap 保持固定高度，四肢关节仍由物理伺服和重力作用
演化。这样可以独立验证控制映射，但不等同于实现自由行走。
