# 双足多步态切换实验报告

## 调度

站立 2 s → 行走 3 s → 快步 3 s → 行走 3 s → 站立 2 s。过渡窗口为 0.65 s，
共 4 次切换。

## 平滑性对照

| 指标 | Hermite | 直接切换 |
| --- | ---: | ---: |
| 最大相邻关节位置差 | 0.0327 | 0.0328 |
| 最大相邻关节速度差 | 0.1839 | 3.8553 |
| 最大有限差分加速度 | 36.78 | 771.06 |

最大相邻速度差降低 95.23%，最大加速度降低 95.23%。位置和速度连续来自
Hermite 端点约束；加速度在过渡开始与结束处仍可能跳变，因此 jerk 没有做
“无限平滑”的结论。

## 文件

- `hermite_trajectory.csv`：平滑切换的六关节数据
- `direct_trajectory.csv`：直接切换对照
- `joint_trajectories.png`：关节角与角速度
- `gait_transition.gif`：侧视双足动画
- `metrics.json`：机器可读指标
