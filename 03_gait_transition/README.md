# 项目三：双足多步态平滑切换

本实验定义六关节双足步态族，运行时依次进入站立、行走、快步、行走、站立。
步态切换有两组实现：

- `direct`：新步态在边界立即接管。
- `hermite`：在 0.65 秒内用三次 Hermite 曲线连接两段步态的关节角与角速度。

代码、曲线生成、调度器、指标、绘图和动画均为独立实现。

## 运行

```powershell
python -m pip install -r requirements.txt
python main.py test
python main.py run
```

也可以运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_assignment.ps1
```

## 结果

- 11 项测试通过。
- 两组轨迹均为 13 秒、2,601 个 200 Hz 采样。
- 直接切换的最大相邻速度差：`3.855 rad/s`
- Hermite 切换的最大相邻速度差：`0.184 rad/s`
- 速度差降低 `95.23%`
- 最大有限差分加速度从 `771.06` 降到 `36.78 rad/s²`

## 方法说明

Hermite 插值在每个边界记录旧步态的位置 `q0` 与速度 `dq0`，并预测过渡结束
时新步态的位置 `q1` 与速度 `dq1`。过渡期间同时用解析导数生成角速度前馈，
所以首拍不会把速度强制清零。该方法保证 C1 连续，但不保证加速度连续。

## 边界

这是关节空间运动学演示，不包含接触求解、质心动力学或 ZMP 平衡。动画和轨迹
用于比较切换连续性，不能证明真实双足机器人不会跌倒。
