# 七轴机械臂键盘控制实验报告

## 实现

机械臂由底座、七个转动连杆、腕部、手掌和两个滑动夹爪组成。七轴使用位置伺服，
键盘每次给目标角增加或减少 0.1 rad，增加值在关节上下限处饱和。

## 测试

| 项目 | 结果 |
| --- | --- |
| 自由度 / 执行器 | 9 / 9 |
| 七轴键位映射 | 通过 |
| 正反向与复位 | 通过 |
| 上下限饱和 | 通过 |
| 阶跃稳态误差 | 0.028 rad |

## 边界

演示不连接真实机械臂，也不调用运动规划器。按键改变的是关节目标角，不是
末端位姿。因此没有逆运动学轨迹、碰撞规避或抓取力控制结论。
